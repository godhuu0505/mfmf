# app-redesign スペック（実機合意 2026-08-03 / D33）

ユーザーから見える振る舞いだけを書く（D16: 画面表・データモデル・RLS はコードが正）。
実装は 4 フェーズ（notes.md 参照）。受け入れ条件は UC 単位で書き、そのまま E2E にする（D25）。

## 合意した骨格

- **ボトムタブバー（案A）**: ホーム / カレンダー / 中央「＋」（クイック記録）/ アルバム / メニュー。
  ラベル付き、アクティブタブは primary 色 + `aria-current="page"`。タブバーはアプリ内画面で常時表示、
  記録フォーム（全画面モーダル型）とゲスト画面・未ログイン画面では出さない
- **viewer** は中央「＋」を抜いた 4 列表示。画面内の作成・編集・削除導線も非表示（現行仕様の維持）
- **メニュータブ**: プロフィール（→ アカウント設定）/ ペット / 体重 / 世帯の設定 / 使い方ガイド /
  ご意見・不具合 / ログアウト（確認ダイアログは現行 AccountMenu と同じ）
- **ブランド色**: primary = オレンジ（light `#c2410c` / dark `#fb923c`）。globals.css のトークン値のみ変更
- **記録フォーム**: キャンセル / 保存とも確認シートを挟む（ゲストのフォームも同様）

## 受け入れ条件（P1: トークン + タブバー + メニュー）

```
UC-N01: どの画面からでも 1 タップで主要画面へ移動できる
  WHEN ログイン済みで任意のアプリ内画面を開く
  THEN 画面下部にタブバー（ホーム/カレンダー/＋/アルバム/メニュー）が表示される
  WHEN 「カレンダー」タブを押す
  THEN /calendar に遷移し、カレンダータブが primary 色 + aria-current="page" になる

UC-N02: 中央「＋」からどの画面でもクイック記録できる
  WHEN カレンダー画面で中央「＋」を押す
  THEN クイック記録シートが下から開く（既存 D32 の chips-first）
  WHEN チップを選んで「保存する」を押す
  THEN シートが閉じ「残しました」が表示され、記録が作成されている

UC-N03: viewer には作成導線が見えない
  WHEN viewer ロールのユーザーでホームを開く
  THEN タブバーは 4 列（中央「＋」なし）で表示される

UC-M01: メニューから体重・設定へ 2 タップ以内で着く
  WHEN 「メニュー」タブを押す
  THEN プロフィール / ペット / 体重の推移 / 世帯の設定 / 使い方ガイド / ご意見・不具合 / ログアウト が並ぶ
  WHEN 「体重の推移」を押す
  THEN /weight が開く（世帯の設定 → /settings も同様）

UC-M02: メニューのログアウトは確認してから
  WHEN メニューで「ログアウト」を押す
  THEN 確認ダイアログが出る。「はい」でログイン画面へ、「いいえ」でメニューに留まる

UC-T01: ブランド色がライト/ダーク両方で適用される
  WHEN ライトモードでログイン画面を開く
  THEN 主ボタンがオレンジ #c2410c で表示される（VRT で担保）
  WHEN ダークモードで開く
  THEN 主ボタンが #fb923c + 濃色文字で表示される（VRT で担保）
```

## 受け入れ条件（P2〜P4 の主なもの）

```
UC-H01: ホームは日付グループのタイムライン
  WHEN 記録が複数日ある状態でホームを開く
  THEN 記録は「今日」「昨日」「M月D日（曜）」の見出しでグループ表示される
  WHEN 虫めがねを押しキーワードを入れ Enter（IME の検索キー含む）
  THEN 本文または記入者にマッチする記録だけが表示され、0 件なら「条件に合う記録がありません」

UC-C01: カレンダーの日タップでその日の記録
  WHEN 記録のある日付をタップ
  THEN その日の記録がボトムシートで開き、タップで詳細へ
  WHEN 記録のない日付をタップ
  THEN 「この日の記録はありません」+ その日付での記録追加導線が出る

UC-F01: 記録フォームの確認ダイアログ
  WHEN フォームで「キャンセル」を押す
  THEN 「編集をやめますか？」が出る。「破棄してもどる」で元の画面へ、「編集を続ける」でフォームに残る
  WHEN 「保存」を押す
  THEN 「この内容で保存しますか？」が出る。「保存する」で保存して遷移する
  （ゲストのフォームも同様。ゲストは預かり期間外の日付を保存できない）

UC-D01: 記録詳細の操作
  WHEN 詳細で「…」を押す
  THEN 編集 / ゲスト共有の切替 / 削除 のシートが出る（削除は確認 → 一覧へ）
  THEN 詳細下部の「前の記録 / 次の記録」で隣の記録へ移動できる

UC-S01: 世帯設定の再構成
  THEN 世帯（画像/名前変更）/ 世帯を切り替え / メンバー（権限変更・削除）/ 招待（リンクコピー付き）/
       外部ゲスト / 危険な操作 がカードで分かれて表示される（操作は現行と同等。オーナー専用は viewer に出さない）
```
