# schedule — 予定と担当、そして「完了したら記録になる」

Artifact: https://claude.ai/code/artifact/8e61a6c0-ccd0-4811-973c-5e7bf22e15fc

## 何をしたいか

mfmf は今、**起きたこと（記録）**しか持っていない。ここに**これからのこと（予定）**を足す。
さらに、保育園の日は **送りが誰・お迎えが誰**を家族で共有したい。

## いちばん大きな決めごと: 予定と記録は別物ではなく、同じものの状態違い

予定を**完了すると記録になる**。1 本のデータに**ステータス**を持たせる。

```
予定（planned） ──「完了して記録にする」──▶ 記録ずみ（done）
      │
      └────────「見送り」──────────────▶ 見送り（skipped） ──「予定に戻す」──▶ 予定
```

- 完了するとき、**種類・時間・担当をそのまま引き継ぐ**。書き直す必要がない
- 完了の画面で、あったこと（定型チップ）・ひとこと・写真を足して記録にする
- 予定を経ずに記録だけ作ることもできる（既存のクイック記録＝最初から `done`）
- 見送り（行かなかった日）は消さずに残る。カレンダーには取り消し線で出る

これで「今日は保育園の予定 →（帰宅後）完了して記録」という 1 日の流れが、
同じカードの上でつながる。

## カレンダー

### 月表示（Google カレンダー風）

日付の下に**チップ**を最大 2 件、あふれたら「他 N 件」。しるしで状態を見分ける。

- **予定** = 中抜きの点
- **記録ずみ** = 塗りつぶしの点（＋写真があればカメラ）
- **見送り** = グレーの取り消し線
- 毎週のルール由来は**薄く**出る

幅に余裕があるとき（sm 以上）は開始時刻も出す。

### 週表示（時間割）

08:00 前後〜21:00 の**時間軸**に、開始〜終了ぶんの高さでブロックを置く。
7 日ぶんを横スクロールで見る（列は 1 日 ≒ 97px）。

- **予定** = 淡い背景＋左に色の線
- **記録ずみ** = 塗りつぶし
- **見送り** = 上部の終日バンドに取り消し線で
- ブロックには時刻と担当のアバターが乗る

「担当をまとめて決める」を開くと、週の 7 日ぶんの送り／お迎えを一気に埋められる
（下書きに貯めて「保存する」で確定）。

## 時間

予定は**開始時刻と終了時刻**を持つ。種類ごとに既定値があり（保育園 9:00〜18:00、
通院 9:30〜11:00 など）、種類を選んだ時点で入る。時間を触っていなければ種類の変更に
追従し、触ったあとは尊重する。終了が開始より前なら保存させない。

## 担当

**担当を独立したフォーム項目にしない**、が出発点。

- **下地: 毎週の予定ルール**（メニュー › 毎週の予定ルール）。いつもの週を一度だけ決めると
  カレンダーに薄く自動で入り、違う日だけ上書きする。種類・**時間**・担当を持つ
- **顔をタップ**。種類を選ぶと、その種類に必要な担当欄だけが現れる（保育園→送り／お迎え、
  おうち→みる人、おでかけ→なし）。アバターを押すだけ
- **いつものパターン**（プロト設定で切替）。名前付きの組み合わせを 1 タップで流し込む

担当は**アカウントに紐づく**。連携済み / 招待中 / 未連携を区別し、未連携の人を担当にしたら
その場で招待に誘導する（連携すると本人のスマホにも予定が出る）。

## 動線（既存のナビを壊さない）

タブバーは**既存の 5 スロットのまま**（ホーム / カレンダー / ＋記録 / アルバム / メニュー）。

| やりたいこと | 動線 |
| --- | --- |
| 予定を入れる・変える | カレンダー › 日をタップ |
| きょうの予定を完了して記録にする | ホームの「きょう」カード／＋シートの先頭／日別シート |
| 週の送り迎えをまとめて決める | カレンダー › 週 › 担当をまとめて決める |
| いつもの週を決める | メニュー › 毎週の予定ルール |
| 担当できる人を増やす・連携する | メニュー › 世帯の設定 |
| 予定と関係なく記録する | ＋（既存のクイック記録。**2 タップのまま**） |

＋シートは、その日に未完了の予定があるときだけ先頭に
「きょうの予定『保育園』を完了にする」を出す。無ければ今までどおり。

## 実機で確かめたいこと

1. **完了 → 記録**の流れが自然か。「完了して記録にする」という言葉で伝わるか
2. 月表示のチップで、予定 / 記録ずみ / 見送りが見分けられるか
3. 週の時間割が、指で見て使える密度か（1 日 97px・横スクロール）
4. 時刻入力（開始・終了）が面倒でないか。終日の予定も要るか
5. 見送りを残す価値があるか（消すのとどちらが自然か）
6. 毎週のルールがメニュー配下で見つかるか
7. 未連携の人を担当にしたときの招待の誘い方がうるさくないか
8. 予定 0 件のとき、viewer のときに画面が成立しているか（プロト設定で切替）

## まだ決めていないこと

- **Google カレンダーへ出すか。** アプリ内 `/calendar` か、家族が普段使う Google カレンダーか。
  このプロトは**アプリ内**。時刻を持たせたので Google 側へ出す下地は揃った
- 1 日に**複数の予定**を持てるようにするか（データは配列だが、編集シートは先頭 1 件だけを扱う。
  月表示は「他 N 件」まで出る）
- 終日予定（時刻なし）を明示的に持つか
- 完了のとき写真を必須にするか（いまは任意）
- 過ぎた予定を**自動で促す**か（前日夜の通知、当日夜に「完了にしますか？」）—— スコープ外

## モックの前提

- 家族 4 人。ママ＝連携済み（オーナー）、パパ＝連携済み（編集者）、ばあば＝未連携、じいじ＝招待中
- 2026-08-09（日）を「今日」とした 2026 年 8 月**のみ**（月の移動はモックしていない）
- 週表示は 8/9（日）〜8/15（土）固定
- `fetch` なし。データは JS の固定配列（`ITEMS` / `RULES` / `MEMBERS`）
- アイコンは lucide の同じ形を SVG で直書き（実装時は `lucide-react` に戻す）
