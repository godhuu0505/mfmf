# AIとの接続 — 承認済みの振る舞い

2026-10-30、利用者がローカル静的画面を確認し「この内容で進めていってください。」と承認した。Claude Artifact用の公開ツールが利用できないため、利用者が明示的に求めたローカル確認環境で同じ静的HTMLを提示し、承認を得た。Claudeクライアントでの実接続試験の延期とは区別する。

## UC-MCP01 ログインして接続の確認へ戻る

- WHEN 未ログインで接続確認のリンクを開く
- THEN 通常のログインへ進み、ログイン後は同じ申し込みの確認画面へ戻る
- THEN 許可は自動で行われず、接続先と閲覧範囲を確認してから利用者が押す
- THEN 認証の有効期限が切れた場合も、安全な同じ確認画面へ戻るログイン案内を表示する

## UC-MCP02 家族を1つ選び、閲覧だけを許可する

- WHEN 接続先から申し込んだ確認画面を開く
- THEN ログイン中のアカウントと、接続先のサービスを表示する
- THEN 正規の管理者・編集者・閲覧者として所属する家族だけを選べる。初めは未選択とする
- WHEN 家族を1つ選び「この家族の記録の閲覧を許可」を押す
- THEN 選んだ家族だけに接続し、許可した接続先へ戻る
- THEN 処理中は選択とボタンを無効にし、連打しても二重送信しない
- THEN 別タブでmfmfの表示中の家族を切り替えても、この接続の家族は変わらない

## UC-MCP03 許可しない・接続できない

- WHEN 家族を選ばずに「許可しない」を押す
- THEN 許可を発行せず接続元へ戻る
- WHEN 正規メンバーとして所属する家族がない、またはゲスト権限だけである
- THEN 許可できず、その理由を表示する。不許可による取り消しはできる
- WHEN 申し込みが期限切れ・完了済み・存在しない
- THEN 許可できず、接続元から申し込み直すよう案内する
- WHEN 接続の準備中、通信エラー、不正な応答、許可されていない戻り先を受け取る
- THEN 成功したように表示せず、原因に合う案内と安全な再確認経路を示す。自動で再送・許可しない

## UC-MCP04 渡る情報を理解する

- THEN 選んだ家族の保存済みの記録の日付・本文・種類・入力済みの体重と、ペットの名前などの基本情報がAIへ渡ると分かる
- THEN 家族が書いた記録も含み、本文中の個人情報が渡ることがあると分かる
- THEN 写真・動画・閲覧用リンク、メンバー一覧・メールなどの会員情報、下書き・削除済みは対象外だと分かる
- THEN 記録の追加・変更・削除・招待はできず、最長30日の接続をいつでも解除できると分かる
- THEN 接続先サービスのデータの扱いに従うことを伝える

## UC-MCP05 接続を見分け、1つだけ解除する

- WHEN 「AIとの接続」を開く
- THEN 自分が許可した接続をサービス名・家族名・接続日時・有効期限で確認できる
- THEN 同じサービス・同じ日の接続も日時の時分秒と接続番号の末尾で見分ける
- WHEN 1つの接続の「接続を解除」を押す
- THEN その接続だけを解除し、成功が確認できてから一覧から取り除く。他の接続は残す
- THEN 解除失敗時は消さずにエラーを表示する。再確認しても自動で解除を再送しない
- THEN 0件なら空の状態を表示し、通信エラーを0件と見せない
- THEN 新しい閲覧は止まるが、AIがすでに受け取った内容は削除されないと分かる

## UC-MCP06 スマートフォン・明暗・情報の扱い

- THEN 360px幅と長い家族名でも横にはみ出さず、ライト・ダークの両方で読める
- THEN キーボードと読み上げで家族選択と操作結果が分かる
- THEN 確認・接続一覧の応答は共有キャッシュやフレーム埋め込みを許可せず、参照元URLを外へ送らない

## 検証の分担

- `tests/e2e/mcp-consent.spec.ts`: 実Nextページ・既存middleware/login・安全な戻り先・実HTTPヘッダー。GCP限定APIは架空応答で操作し、本番認証の代用とは扱わない。
- `tests/mcp-ui/`: 製品のReact部品そのものを隔離したブラウザで操作。APIの架空応答だけをテスト側から与える。GCPモードのブラウザAPI契約と明暗を確認するが、実IdP/RLS受入とは扱わない。
- 既存のOAuth・API単体・Firestore・実PostgreSQL/PostgRESTのテスト: 認証・CSRF・所属・世帯固定・失効を実装境界で検証する。これらを省略・緩和しない。
