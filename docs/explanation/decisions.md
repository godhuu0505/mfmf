# 設計決定ログ（D ログ）

**このリポジトリで唯一「維持する価値がある」ドキュメント。**
現状の仕様（画面一覧・機能一覧・データモデル）は AI にコードを読ませれば数秒で分かるので書きません。
一方、**採用しなかった案とその理由はコードに痕跡が残らない**ため、ここにだけ残します。

なぜこの方針なのかは [prototype-first.md §4-5](./prototype-first.md) を参照。

## 書き方（守るのはこれだけ）

- **1 決定 = 1 行。** 長く書かない。長い説明が要るなら別ドキュメントに切り出してリンクする
- **却下した案とその理由を必ず含める。** これが本ログの存在理由。「Xを採用」だけでは半分の価値しかない
- 番号は `D<n>` の通し番号。**欠番にしない・振り直さない**（commit 件名から参照されるため）
- commit 件名で `Dx` を引用する既存の慣習を続ける（例: `feat: S4 ゲスト閲覧/記入 UI（UC-G02/G03・D4/UC-S01）`）
- **実装しなかった決定こそ書く。** 実装 PR が発生しないので忘れやすいが、価値は最も高い
