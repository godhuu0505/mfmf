# 記録を関連度で探す

既存の検索パネルへ、利用者が明示して押す「関連度で探す」を追加する案。
通常のキーワード検索・日付/体重順の動作は変えない。

- 既存の条件で閲覧できる最近の最大100件を対象とし、対象範囲が分かる。
- Google Cloudへ外部処理すること、送信内容、東京内処理の保証がないことを押す前に説明する。
- 日付や数値の質問は通常検索/絞り込みを使う。数字列を伏せるが、漢数字など完全な数値の匿名化は保証しない。AIによる健康評価は行わない。
- 0件、利用上限、通信失敗でも通常検索へ戻れる。
- 画面は固定の架空データだけで動き、アプリ・DB・外部APIへ接続しない。

CLAUDE.md D24の先行プロト。Claude Artifactの公開ツールがこの実行環境にないため、
同じ自己完結HTMLをローカル静的プレビューとモバイル画像で確認する。
2026-10-28に利用者が画面案を了承し、実装・CI・レビュー・公開・有効化まで進めるよう依頼した。
受け入れ条件は`spec.md`に記録した。
