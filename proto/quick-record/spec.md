# クイック記録 — スペック（ユーザーから見える振る舞い）

プロト合意: 2026-08-02（案 A: チップ主体を採用 → D32）。
画面表・データモデル・RLS は書かない（コードが正 = D16）。

## 何ができるか

ホーム（記録一覧）右下の「クイック記録」ボタンから、**画面遷移なしで**
テキストの記録を 1 件残せる。IME を開かなくても定型チップだけで完結する。

- ボタンを押すとシートが下から出る。日付は**今日**、どこでのできごとかは**おうち**が既定
- 定型チップ（ごはん完食 / ごはん少なめ / おやつ / さんぽ / トイレOK / おくすり / ねんね / ごきげん）を
  タップで選ぶ。選んだ順に「、」で繋がって本文になる
- 「＋ ひとことを足す」で 1 行テキストを足せる（任意）
- 本文が空のあいだ「保存する」は押せない
- 保存するとシートが閉じ、**一覧の先頭**に追加され、「残しました」と一言出る。
  シートの選択はリセットされる（次回はまっさら＋おうちに戻る）
- 記入者はプロフィールの既定記入者を自動で使う（画面には出さない）
- 写真・体重・タグ・ペット・日付変更が要るときは従来の「＋ 新規」（フル記録）を使う
- viewer（閲覧のみ）にはボタン自体が出ない

## 受け入れ条件（E2E = tests/e2e/quick-record.spec.ts）

```
UC-Q01: チップだけで残す（IME 不要）
  WHEN ホームで「クイック記録」を押す
  THEN シートが下から出る（今日の日付・「おうち」選択済み）
  WHEN 「ごはん完食」を選んで「保存する」を押す
  THEN シートが閉じ「残しました」が出て、一覧の先頭に今日の日付・おうち・「ごはん完食」が出る

UC-Q02: チップ＋ひとことの合成と永続化
  WHEN チップ 2 つと「＋ ひとことを足す」からひとことを入れて保存する
  THEN 本文は「チップ、チップ、ひとこと」の形で先頭に出る
  THEN リロードしても残っている

UC-Q03: 空では保存できない
  WHEN シートを開いた直後
  THEN 「保存する」は押せない
  WHEN チップを選ぶ → 外す
  THEN 押せる → また押せなくなる

UC-Q04: 保育園に切り替えて残す
  WHEN 「保育園」を選んで保存する
  THEN 先頭のカードに「保育園」のバッジが付く

UC-Q05: キーボードで閉じられる
  WHEN シートを開いて Escape を押す
  THEN シートが閉じ、フォーカスが「クイック記録」ボタンへ戻る
```

**この PR で E2E にしないもの（先送りの記録）**

- viewer にボタンが出ないこと・viewer が Server Action を呼べないこと →
  viewer ユーザーの seed が要るため PR-C（Integration 基盤）で検証する。
  一次防衛線は RLS（pgTAP が担保済み）
- 写真つきクイック記録 → 対象外（フル記録を使う）。E2E 2 本目の題材
- オフライン時の挙動 → PWA/System 網羅（PR-E）で扱う
