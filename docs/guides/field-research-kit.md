# 解像度を上げるためのフィールドキット

[pet-market-research.md](../explanation/pet-market-research.md) の18本のペイン仮説は**すべて机上**です。
本書は、それを**実在の数字と実在の人の言葉に置き換える**ための手順書です。

- 各アクションに **所要時間・費用・何が分岐するか・撤退基準** を書いています
- **撤退基準は着手前に決めておく**（数字を見てから基準を作ると必ず自分に甘くなる）
- 順序は「安い順 × 決定力の高い順」

---

## 全体像 — 3日・3週間・3ヶ月

| フェーズ | 期間 | 費用 | やること | 判明すること |
| --- | --- | --- | --- | --- |
| **Phase 0** | **3日** | ¥0 | 机上で潰せるものを潰す（§1） | **仮説1が既に死んでいないか** |
| **Phase 1** | **3週間** | 交通費のみ | 人に会う（§2） | ペインの**実在・頻度・支払実績** |
| **Phase 2** | **3ヶ月** | 数万円 | 手で提供してみる（§3） | **金を払う人がいるか** |

> 🔑 **Phase 0 を飛ばして人に会いに行かないこと。** §1-4 の1時間で仮説1が死ぬ可能性があり、
> その場合の20軒の訪問は丸ごと無駄になります。

# §1. Phase 0 — 3日でできる、¥0 の調査

## 1-1. 【最優先・所要2時間】既存の「無料の相談サービス」を棚卸しする

> **これが仮説1（トリアージの空白）の最大の反証になり得ます。**
> ペット保険には**獣医師相談が無料付帯**しているものがあり、もし十分に普及していれば
> 「相談の行き先が無い」という前提自体が崩れます。

### やること

1. 次を検索して、**実在するサービスを10個以上**表に起こす
   - 「ペット保険 獣医師 相談 無料」「犬 オンライン 獣医 相談」「ペット 健康相談 LINE」
   - 保険各社（アニコム・アイペット・au・楽天・PS保険 …）の**付帯サービス欄**を全部見る
   - 生成AI（ChatGPT / Gemini）に実際に「犬が朝から下痢、病院行くべき？」と聞いてみる
2. 各サービスについて記録する

| 記録項目 | なぜ要るか |
| --- | --- |
| 提供者（保険会社/独立/AI） | 誰が金を出しているか |
| 料金（無料 / 従量 / 保険付帯） | **無料が主流なら課金モデルが死ぬ** |
| 回答者（獣医師 / 看護師 / AI / 不明） | 供給の実体 |
| 回答までの時間 | 「困った瞬間」に間に合うか |
| 利用条件（契約者限定か） | **未加入の8割はどうしているのか** |
| レビュー・不満の声 | 空白がどこに残っているか |

### 🔴 撤退基準（先に決める）

- 無料の獣医師相談が**保険契約者向けに広く付帯**していて、
  かつ**生成AIの回答が実用的**なら → **仮説1は「相談そのもの」では成立しない**
- その場合の生き残り筋は1つだけ:
  **「一般論の回答」ではなく「この地域のこの病院に、今日行くべき」まで繋ぐこと**
  → 仮説を**相談業から送客業へ**書き換える（＝ [strategy-zero-based.md](../explanation/strategy-zero-based.md) に戻る）

## 1-2. 【最優先・所要1時間】1地域の施設密度を出す

> **比較サイト／送客モデルの生死を分ける唯一の数字。**

### やること

1. 自分が動ける自治体の登録簿を1つ取得する
   - [柏市（Excel オープンデータ）](https://www.city.kashiwa.lg.jp/dobutsuaigo/shiseijoho/jouhoukoukai/opendate/animal_dealer.html)
   - [埼玉県](https://www.pref.saitama.lg.jp/a0706/doubutu-touroku/toriatukaimeibo.html)
   - [全国リンク集](https://animals-peace.net/companionanimal/link)
2. Excel を CSV で保存して実行する

```bash
node scripts/survey-facilities.mjs <保存したCSV> --samples 100
```

3. 出力から次を読む

| 見る場所 | 意味 |
| --- | --- |
| `業種列=「…」` と `⚠` 行 | **CSV を正しく読めているか**（ここが崩れていたら以降の数字は無意味） |
| 保管の件数 | 預かり業態の**上限（天井）** |
| 保管内の不明率 | **40%超なら推定に使えない**。目視補正が要る |
| 対象業態の比率 下限/上限 | 推定のブレ幅 |
| 🎯 **保育園・訓練の実数** | **その自治体に何軒あるか** |

4. **地図に落とす**（Google マイマップで十分）。自分の可動域（車で30分）に何軒あるか数える

### 🔴 撤退基準

| 可動域内の軒数 | 判定 |
| --- | --- |
| **3軒未満** | 🔴 **比較・送客モデルは成立しない**。飼い主は近い1択で選ぶ → 別の仮説へ |
| 3〜9軒 | 🟡 成立し得るが、1地域の売上上限が低い。**横展開が前提** |
| 10軒以上 | 🟢 比較の価値がある。この地域から始める |

## 1-3. 【所要3時間】獣医療行為の線引きを、条文で確認する

> **仮説1が合法かどうか。ここが黒なら事業自体が存在できません。**

### 読むもの

| 資料 | 見るポイント |
| --- | --- |
| **獣医師法 第17条** | 「獣医師でなければ、飼育動物の**診療を業務としてはならない**」— **「診療」の範囲** |
| **獣医療法** | 広告規制。「治る」「効く」と言えない範囲 |
| **愛玩動物看護師法**（2022年施行） | 国家資格化された看護師が**できること／できないこと**（採血・投薬の一部が可能に） |
| 農林水産省の通知・Q&A | 「診療」の解釈、遠隔診療の扱い |

### 整理する表（自分で埋める）

| 行為 | 獣医師でなくても可か | 根拠 |
| --- | --- | --- |
| 「この症状は病院に行くべき」と一般論を述べる | ？ | |
| 個体の症状を聞いて「様子見でよい」と述べる | ？ | |
| 「〇〇病の可能性があります」と述べる | ？ | |
| 病院を紹介する（受診勧奨） | ？ | |
| 飼い主の記録を整理して獣医に渡す | ？ | |

### 🔴 撤退基準

- **「個体の症状を聞いて受診の要否を答える」が診療に当たる**なら、
  → 仮説1は**獣医師を巻き込む形でしか成立しない**（＝自分は場の提供者に徹する）
- 条文で判断がつかないときは、§2-1 のヒアリングで**獣医師に直接聞く**（無料で最も確かな情報源）

## 1-4. 【所要2時間】自分の可動域の動物病院を実地で数える

### やること

1. Google マップで「動物病院」を検索し、**車で30分圏**を全部リストにする
2. 各病院のサイトで次を記録する

| 記録項目 | 何が分かるか |
| --- | --- |
| 獣医師の人数 | 1人体制か（**1.28人/院**という全国平均が自分の地域でも成り立つか） |
| 電話相談の可否・時間 | **相談の受け皿がどれだけあるか** |
| 予約制か、待ち時間の記載 | 混雑度 |
| 「しつけ相談」「パピー教室」の有無 | **病院が既に相談を抱えている**か |
| 提携先の記載（保育園・トリマー） | **紹介の流れが既にあるか** |

3. **Google マップの口コミを50件読む**（★1〜2を優先）
   → 「待たされた」「相談できなかった」「説明が短い」が出るかを数える
   → **不満の言語**がそのまま §2 の質問文になる

# §2. Phase 1 — 3週間、人に会う

## 質問設計の大原則（これを外すと全部無駄になる）

| ❌ 聞いてはいけない | ✅ 聞くべき |
| --- | --- |
| 「こういうサービスがあったら使いますか？」 | 「**直近でそれが起きたのはいつですか？**」 |
| 「いくらなら払いますか？」 | 「**そのとき実際にいくら払いましたか？**」 |
| 「〇〇に困っていますか？」 | 「**先週、何に一番時間を取られましたか？**」 |
| 「便利だと思いますか？」 | 「**今はどうやって解決していますか？**」 |

> 🔑 **未来の意向は嘘になる。過去の行動は嘘にならない。**
> 相手は親切心で「使うと思う」と言います。それは**データではありません**。

---

## 2-1. 動物病院 10軒（最重要）

**入り方**: 「提携させてください」ではなく「**教えてください**」。
名乗りは「ペットの飼い主が困ったときの相談先を調べている個人です」で十分。
診療時間外・昼休みの終わりを狙う。**5分で終わらせる**と最初に言う。

### 聞くこと（この順で）

1. 「**今日、電話での問い合わせは何件くらいありましたか？**」
2. 「そのうち、**結果的に来院しなくてよかったもの**はどれくらいですか？」
3. 「その電話は**誰が取っていますか**？ その間、何が止まりますか？」
4. 「**"様子見でいいですか"という電話**、多いですか？ 増えていますか？」
5. 「**保育園やトレーナーを紹介すること**はありますか？ どこを紹介していますか？ **なぜそこですか？**」
6. 「紹介先を選ぶとき、**何が分かれば安心して紹介できます**か？」
7. （最後に）「この手の相談を**外部が受けてくれる**としたら、**任せたいですか、任せたくないですか？**」

### 記録シート

| 病院 | 獣医師数 | 1日の電話件数 | うち不要来院 | 誰が取る | 紹介先 | 選ぶ基準 | 外部委託への反応 |
| --- | --- | --- | --- | --- | --- | --- | --- |

### 🔴 判定基準

| 結果 | 意味 |
| --- | --- |
| 電話が**1日10件以上**で、その多くが「様子見でいいか」 | 🟢 **ペインは実在する** |
| 「そんなに来ない」「困っていない」が過半 | 🔴 仮説1の前提（F4）が自分の地域では成り立たない |
| 「外部には任せたくない」が過半 | 🟡 **病院を通さない形**（飼い主直販）に切り替え |
| 紹介先を**具体名で即答**できる | 🟢 紹介の流れが既にある＝送客が成立する |
| 「紹介したことがない」が過半 | 🔴 送客モデルの前提が崩れる |

---

## 2-2. 飼い主 20人

**どこで**: ドッグラン、公園、行きつけのトリミング、SNS、知人。
**入り方**: 「アンケートじゃなくて、**最近困ったことを教えてほしい**」。3分。

### 聞くこと

1. 「**直近で"これ病院行くべき？"と迷ったのはいつ**ですか？ 何がありましたか？」
2. 「そのとき、**最初に何をしましたか**？」（検索 / SNS / AI / 知人 / 病院に電話 / 様子見）
3. 「**迷っていた時間**はどれくらいですか？」
4. 「**結局どうしました**か？ **いくらかかりました**か？」
5. 「**今までで一番お金がかかったこと**は何ですか？」
6. 「**預けなきゃいけなくなったこと**はありますか？ どうしましたか？」
7. 「しつけで困ったとき、**誰に聞きました**か？」

### 記録シート

| # | 犬種/年齢 | 直近の"迷い" | 初動 | 迷った時間 | 結果 | 支払額 | 最大支出 | 預けた経験 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |

### 🔴 判定基準

| 結果 | 意味 |
| --- | --- |
| 「迷った」経験が**20人中15人以上** | 🟢 P1/P2 は広い |
| 初動が**検索・AI**に集中 | 🔴 **既に無料で解決されている**。§1-1 の結論と突き合わせる |
| 初動が**病院に電話**に集中 | 🟢 §2-1 の結果と整合＝F4 の裏づけ |
| 迷った時間が**数日以上**が多い | 🟢 痛みが深い（放置＝リスク） |
| 「預けなきゃいけなくなった」が**5人以上** | 🟢 P3/P7（仮説2）の頻度が想定より高い |

## 2-3. 犬の保育園・預かり施設 5軒（送客モデルの検証）

**入り方**: 「見学させてください」＋「掲載してもいいですか（無料）」。

### 聞くこと

1. 「**今の在籍は何頭**ですか？ **定員**は？」 ← **空きが無ければ送客に価値がない**
2. 「**直近で入園した5頭は、どこから来ました**か？」（紹介 / 検索 / SNS / 通りがかり / 病院）
3. 「**体験申込は月何件**ですか？ そのうち**何件が入園**しますか？」
4. 「**今まで広告にいくら使ったこと**がありますか？ 何に？ 効きましたか？」
5. 「1頭増えると、**月にいくら増えます**か？」
6. 「新しい飼い主さんを紹介してもらえたら、**成果報酬でいくらまで**払ったことがありますか？」

### 🔴 判定基準

| 結果 | 意味 |
| --- | --- |
| **定員に空きがある**施設が過半 | 🟢 送客に価値がある |
| ほぼ満員 | 🔴 **送客は要らない**。売るものが変わる（＝業務効率化へ） |
| 入園経路が**紹介・口コミ**に集中 | 🟡 紹介元を押さえる戦略と整合（＝ KSF の裏づけ） |
| 入園経路が**検索**に集中 | 🟡 SEO/広告の戦い＝個人には不利 |
| 過去に広告費を**払った実績がある** | 🟢 **支払意思の実証**（意向ではない） |
| 「広告は一度も出していない」が過半 | 🔴 **予算そのものが存在しない** |

---

## 2-4. 老犬ホーム・預かりサービス 3軒（仮説2の検証）

### 聞くこと

1. 「**直近1ヶ月で、断った問い合わせは何件**ですか？」 ← **需要超過の直接証拠**
2. 「問い合わせから**入居までの日数**は？」
3. 「**"明日から"という緊急の依頼**は月何件ですか？ 受けられますか？」
4. 「**断る理由**は何が多いですか？」（満床 / 症状 / 費用 / 期間）
5. 「入居のきっかけは何が多いですか？」（飼い主の入院 / 高齢 / 介護疲れ / 転居）

### 🔴 判定基準

- 「**断っている**」が月5件以上 → 🟢 需要が供給を超えている（仮説2が生きる）
- 「**空いている**」 → 🔴 需要超過は思い込み。老犬ホームの急増は供給過剰かもしれない

## 2-5. ブリーダー 3軒（仮説3の検証・任意）

> 🔴 **優先度は最も低い**。市場が縮小方向で、社会的にセンシティブ。
> 仮説1・2が両方死んだときの**予備**として位置づける。

1. 「**数値規制の完全施行で、頭数はどう変わりました**か？」
2. 「**繁殖引退犬の行き先**はどう確保していますか？」
3. 「**販売はどこ経由**ですか？ 手数料はどれくらいですか？」
4. 「**マイクロチップの登録事務**にどれくらい時間がかかっていますか？」

# §3. Phase 2 — 3ヶ月、手で提供してみる

Phase 1 で仮説が生き残ったら、**ソフトウェアを作る前に人力でやる**。

| 仮説 | 人力での最小提供 | 検証すること |
| --- | --- | --- |
| **1. トリアージ** | 獣医師/愛玩動物看護師の**空き時間を時給で買い**、LINE で飼い主の質問に答える。自分は取次ぎのみ | **飼い主が金を払うか**／**専門家が時間を売るか** |
| **2. 預け先** | 地域の預かり先の空き状況を**電話で聞いて回り**、スプレッドシートで管理。問い合わせに手で答える | **緊急依頼が実際に来るか**／**成約するか** |
| **3. 送客** | 施設の比較ページを**手書きで作り**、紹介カードを病院に置く | **月10件の体験申込**（[KSF の指標](../explanation/strategy-zero-based.md)） |

### 共通の撤退基準

> **3ヶ月で、"自分に金を払った人"が1人も出なければ撤退**。
> 「興味がある」「応援している」「使ってみたい」は**すべて0円**として数える。

# §4. 3日で終わる最短ルート（今日やること）

| 順 | やること | 時間 | これで何が決まるか |
| --- | --- | --- | --- |
| **1** | §1-1 無料相談サービスの棚卸し | 2h | **仮説1が生きているか** |
| **2** | §1-2 登録簿 CSV → 密度 | 1h | **送客モデルが生きているか** |
| **3** | §1-4 可動域の動物病院リスト＋口コミ50件 | 2h | **ヒアリング先の確保**＋不満の言語 |
| **4** | §1-3 獣医師法・愛玩動物看護師法 | 3h | **仮説1が合法か** |

**この4つ（計8時間・¥0）で、18本の仮説のうち少なくとも半分は生死が判定できます。**

そのうえで §2 に進み、**3週間で33人**（病院10・飼い主20・施設5・老犬ホーム3）に会う。
ここまでで**解像度は机上の仮説から実測に変わります**。
