# schedule — 予定（これからの日）と、送り／お迎えの担当

Artifact: https://claude.ai/code/artifact/8e61a6c0-ccd0-4811-973c-5e7bf22e15fc

## 何をしたいか

mfmf は今、**起きたこと（記録）**しか持っていない。ここに**これからのこと（予定）**を足す。

- 来週の水曜は保育園に預ける日
- 今日はばあばが来てくれる日
- 明日はママが在宅で見る日

さらに、保育園の日は **送りが誰・お迎えが誰**を家族で共有したい。

## 決まったこと

- **毎週のルールを下地にする。** いつもの週を一度だけ登録し、カレンダーに薄く自動で入れる。
  違う日だけ上書きする。担当の入れかたを切り替えても**ルールは常に効いている**
- **担当はアカウントに紐づける。** 担当に選べるのは世帯のメンバー。連携済みの人は
  自分のスマホでも予定が見える。未連携の人（ばあば等）も担当には選べるが、
  その場で招待に誘導する

## 中心にある問い

> 「担当を登録できるといい。項目としてある必要はないんだけど、なんかいい登録方法ってないかな」

**担当を独立したフォーム項目にしない**、という制約が本質。3 つの答えを重ねている。

### 下地: 毎週のルール（メニュー › 毎週の予定ルール）

「月火木金は保育園、水はママが在宅」を一度だけ登録。カレンダーには**薄い**しるしで
自動的に入り、**違う日だけ上書き**する。日々の登録操作そのものが消えるのが狙い。
シートの「これから毎週◯曜も同じにする」からも作れる（**編集した日以降**にだけ効く）。

### 入れかた1: 顔をタップ（プロト設定で切替）

予定の種類を選ぶと、**その種類に必要な担当欄だけが後から現れる**。
「保育園」なら 送り／お迎え、「おうち」なら みる人、「おでかけ」なら何も出ない。
入力はテキストでもプルダウンでもなく、**メンバーのアバターを押すだけ**（もう一度押すと解除）。

### 入れかた2: いつものパターン（プロト設定で切替）

「いつもの保育園（送りパパ／迎えママ）」のような**組み合わせを名前付きで保存**し、
シートの一番上に並べる。**1 タップで種類と担当が同時に埋まる**。

## 動線（既存のナビを壊さない）

タブバーは**既存の 5 スロットのまま**（ホーム / カレンダー / ＋記録 / アルバム / メニュー）。
予定のために新しいタブは足さない。

| やりたいこと | 動線 |
| --- | --- |
| 予定を入れる・変える | カレンダー › 日をタップ（主導線） |
| きょうの予定と担当を見る | ホームの「きょうの予定」カード |
| 今週の送り迎えをまとめて埋める | カレンダー › **週（担当）**タブ（日〜土の 7 日） |
| いつもの週を決める | メニュー › 毎週の予定ルール |
| 担当できる人を増やす・連携する | メニュー › 世帯の設定（担当ピッカーからも直接） |
| 記録する | ＋（既存のクイック記録。**2 タップのまま増やさない**） |

＋シートの最下部にだけ「これからの予定を入れる →」を置いた。
記録のつもりで開いたが予定だった、という取り違えの受け皿。

## カレンダーでの予定と記録の見分け

既存の月グリッド（`CalendarMonth`）の見た目はそのまま。**しるしの形で区別**する。

- **予定** = 中抜きの点（種類ごとの色）。曜日ルール由来は**薄く**出る
- **記録** = 塗りつぶしの点（既存のまま。青=保育園 / 橙=おうち）

見分けやすさは実機で決めたいので、プロト設定で **中抜きの点 / 日付の下のライン / 絵文字**
の 3 通りを切り替えられるようにしてある。

## 実機で確かめたいこと

1. **予定と記録の見分けがつくか。** 3 通りのうちどれが一番わかりやすいか
2. 曜日ルール由来（薄い）と、手で入れた予定（濃い）の差が説明なしで伝わるか
3. **担当の入れかた**は「顔をタップ」と「いつものパターン」のどちらが要るか。両方要るか
4. 週（担当）タブが、カレンダーの中にあるのが自然か
5. 毎週の予定ルールがメニュー配下で見つかるか（毎日触るものではない想定）
6. 未連携の人（ばあば）を担当にしたときの招待の誘い方がうるさくないか
7. ホームの「きょうの予定」カードが、朝いちばんに見たいものになっているか
8. 予定 0 件のとき、viewer のときに画面が成立しているか（プロト設定で切替）
9. シートの編集は「予定を保存する」で確定・✕ と背景タップで破棄にしてある。
   本番の記録フォームはキャンセル時に確認ダイアログを挟む決定があるので、揃えるかどうか

## まだ決めていないこと

- **Google カレンダーへ出すか。** 「カレンダーにも反映される」がアプリ内の `/calendar` を
  指すのか、家族が普段使っている Google カレンダーを指すのかで実装量が桁で変わる。
  このプロトは**アプリ内 `/calendar`**
- 予定は **1 日 1 件**にしてある（種類は単一選択）。「保育園＋通院」を同日に書きたくなるか
- 時刻を持たせるか（いまはメモに「9:30 ワクチン」と書く前提の終日予定）
- 予定の日が来たら**記録の下書き**にするか（シートの「この日の記録を追加（保育園）」）
- 通知（前日の夜に「明日はパパが送りです」）—— 今回のスコープ外
- 担当を **viewer や外部ゲスト**にも割り当てられるようにするか

## モックの前提

- 家族 4 人。ママ＝連携済み（オーナー）、パパ＝連携済み（編集者）、ばあば＝未連携、じいじ＝招待中
- 2026-08-09（日）を「今日」とした 2026 年 8 月**のみ**（月の移動はモックしていない）
- `fetch` なし。データは JS の固定配列（`PLANS` / `RULES` / `RECORDS` / `MEMBERS`）
- アイコンは lucide の同じ形を SVG で直書き（実装時は `lucide-react` に戻す）
