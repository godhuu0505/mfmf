# 関連度で記録を探す

2026-10-28に、静的プロトの画面案と、実装・CI・レビュー・公開・有効化まで進めることについて利用者の明示了承を得た。
Claude Artifactの公開機能がないため、自己完結HTMLのローカル表示とモバイル画像で画面案を提示した。

## 利用者から見える振る舞い

既存の検索・絞り込みパネルで、いつものキーワード検索に加えて「関連度で探す」を選べる。
質問を入力しただけでは送信しない。Google Cloudへ送る内容と、完全な匿名化や東京内での処理を保証しないことを押す前に読める。
日付や記録元・タグで絞った、閲覧できる最近の最大100件を対象にする。数値や健康状態を評価しない。

関連度の結果は、対象件数と短い本文・記録日・記録元を表示し、元の記録を開ける。
通常の記録一覧や既存の検索は引き続き使え、関連度表示からいつでも戻れる。
記録がない場合、利用上限、期限切れ、通信・ログインの問題は理由を示して通常検索を残す。
利用者ごと1日20回までで、全体の利用枠に達した場合は早く終了することがある。

## 受け入れ条件

- UC-R01: パネルを開く・入力する・条件を変更する・再読み込みでは関連度検索を送信しない。「関連度で探す」を押した1回だけ送る。
- UC-R02: 処理中は状態と二重送信防止を示す。成功時、対象件数・関連度順の記録・元の記録へのリンクが表示される。
- UC-R03: 入力・日付・並び替え・記録元・タグ・現在世帯が変わったときは関連度結果と未完了処理を無効にする。遅れて届く成功・失敗が新しい入力や結果を上書きしない。
- UC-R04: 「通常検索に戻す」、通常検索の実行、条件のクリア、パネルを閉じる操作でも未完了処理を無効にする。
- UC-R05: 0件、上限、期限・設定の無効、通信失敗では通常検索を使える案内を出し、架空の結果や古い結果を表示しない。
- UC-R06: 未ログイン時は既存のログインへ進む。表示・返却範囲は現在の認証・世帯の権限を超えない。
- UC-R07: 正規の有効化設定がない場合、新しい送信ボタンは表示しない。通常検索は元のまま使える。
- UC-R08: モバイルの明暗画面で説明・入力・ボタン・結果がはみ出さず、キーボード操作と読み上げで状態が分かる。

E2Eはローカルの実認証を通し、テスト側だけでServer Actionの応答を差し替える。
テスト用NodeプロセスではGoogleの認証・Ranking通信を拒否する。アプリ本体に認証回避や架空API実行の設定は加えない。
