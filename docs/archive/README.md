# archive/ — 役目を終えたプロトタイプとスペック

マージ済み機能のプロトタイプ（`proto/<slug>/`）とスペックはここへ移します。
**削除はしません**（[D27](../explanation/decisions.md)）。

```
docs/archive/<slug>/
├── index.html      ← 合意した時点のプロトタイプ
├── notes.md
└── spec.md
```

## ここにあるものの読み方

- **現状の仕様ではありません。** 「合意した時点のスナップショット」です。
  現在の振る舞いの正はコードと E2E テスト（[D16](../explanation/decisions.md) /
  [D26](../explanation/decisions.md)）
- 読み返す価値があるのは「**なぜその形にしたか**」「**何を却下したか**」です。
  実際に `76a2406` は、半年前に未決事項へ書いた論点を人間が読み返して決着させたコミットです
- 決定そのものの正は [decisions.md](../explanation/decisions.md)（D ログ）

## なぜ消さないか

一時的な設計物を**永続的に現役の場所へ置く**と、それ自体が「どれが最新か分からない」
腐敗源になります。かといって**消す**と、半年後に同じ検討をやり直します。
アーカイブはその中間で、「現役ではないが読み返せる」状態を作るためのものです。

> ⚠️ **移動を自動化する CI はまだありません。** 当面は手で移動してください。
